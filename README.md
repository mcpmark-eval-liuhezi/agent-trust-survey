# agent-trust-survey

A starter reading packet for a new research project on **human trust in answers from
conversational, LLM-powered search agents**.

## Scope

This repository collects and summarizes literature on how much people trust the
information they get from:

- LLM-powered conversational search interfaces (e.g., AI-generated answers and
  "AI Overviews" embedded in search results)
- Conversational agents and chatbots used for information seeking
- Agentic LLM systems that retrieve and synthesize answers on a user's behalf

## Contents

- `survey.md` — summaries of the most relevant papers found on arXiv. Each entry
  includes the arXiv ID, full title, author list, and a short paragraph of
  takeaways so new team members can decide what to read in depth.

## How to use this

1. Read `survey.md` first for the lay of the land.
2. Pull each paper by its arXiv ID (`https://arxiv.org/abs/<ID>`) and skim the
   abstract and figures before diving into the method sections.
3. Add new entries via pull request; keep the same per-paper format
   (arXiv ID, title, authors, takeaways paragraph).
